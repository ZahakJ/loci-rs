# Code of conduct

- Be courteous. Disagree with ideas, not with people.
- Assume good faith; ask before concluding.
- No harassment, personal attacks or discrimination, in issues, pull requests, reviews or anywhere the project is discussed.
- Keep private things private: no personal data, no real decks, no screenshots of other people's notes.

Report problems in an issue, or privately through the repository's security advisory form. Serious breaches lead to removal from the project's spaces.
