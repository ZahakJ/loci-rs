# Loci in the browser

Loci runs in a web browser at [zahakj.github.io/loci-rs/app](https://zahakj.github.io/loci-rs/app/): the same app and engine as the desktop and Android builds, compiled to WebAssembly. Nothing is sent to a server.

## Install it

Open the address in Chrome, Edge, Safari or Firefox. To keep it like an app, with its own window and icon:

- **Chrome and Edge:** the install icon at the right of the address bar, or the menu › *Install Loci*.
- **Safari on iPhone and iPad:** Share › *Add to Home Screen*.
- **Safari on a Mac:** File › *Add to Dock*.
- **Chrome on Android:** the menu › *Add to Home screen*.

## Where your data lives

Your collection, media and automatic backups are stored inside this browser, for this site only. Another browser, another device or a private window starts with an empty collection.

To keep it in step with other devices, use [sync](sync.md). To move it, use *Settings › Backups › Download full backup* and import that file in *Replace* mode on the other side; full backups move freely between the browser, desktop and Android builds.

Clearing this site's data deletes the collection. Keep a recent full backup outside the browser.

Loci is open in one tab at a time. A second tab says *Loci is open in another tab*; close one of them and reload.

## Offline

After the first visit Loci works without a connection. A new version loads in the background on a visit online and takes effect on the next one.
