# Loci in the browser

Loci runs in a web browser at [zahakj.github.io/loci-rs/app](https://zahakj.github.io/loci-rs/app/). It is the same app as the desktop and Android builds, with the same engine, compiled to WebAssembly. Nothing is sent to a server: the page loads once, then everything happens on your device.

## Install it

Open the address in Chrome, Edge, Safari or Firefox. To keep it like an app, with its own window and icon:

- **Chrome and Edge:** the install icon at the right of the address bar, or the menu › *Install Loci*.
- **Safari on iPhone and iPad:** Share › *Add to Home Screen*.
- **Safari on a Mac:** File › *Add to Dock*.
- **Chrome on Android:** the menu › *Add to Home screen*.

## Where your data lives

Your collection, media and automatic backups are stored inside this browser, for this site only. Another browser, another device or a private window starts with an empty collection.

To move your collection, use *Settings › Backups › Download full backup*, then open Loci where you want it and import that file in *Replace* mode. The same file restores a desktop or Android install, and a full backup from those restores here.

Clearing this site's data in the browser settings deletes the collection. Download a full backup from time to time and keep it somewhere safe.

Loci is open in one tab at a time. A second tab says *Loci is open in another tab*; close one of them and reload.

## Offline

After the first visit Loci works without a connection: open it from the address or the installed icon as usual. When a new version is published, the next visit online loads it in the background and the one after uses it.
