Spaced repetition for Linux, Windows, macOS and Android.

Imports Anki collections with their review history and due dates, schedules with FSRS-6 or SM-2, and exports back to .apkg.

Download Open in your browser Read the manual

Screens

Study

Four grades, fixed in place

  • Again, Hard, Good and Easy each show the interval they would give.
  • Keys 1–4 grade; space shows the answer, then means Good.
  • i shows retrievability, stability, difficulty and the last reviews.

Workload

Catch-up

  • A backlog is shown in minutes, with four plans: spread over several days, today's share only, lower retention for a week, or study everything. Each is undoable.
  • Daily limits are a time budget, not card caps.
  • Days studied in the last 30 instead of streaks.

Browse and add

Anki search syntax

  • deck:, tag:, is:due, prop:r<0.8, rated:7, phrases, OR and parentheses.
  • Bulk change deck, tags, suspend, flag, set due date, forget, find and replace. All undoable.
  • a adds a note: cloze and image occlusion in Anki's format.

Features

  • Anki import and exportReads .apkg and .colpkg in every layout: notes, note types, templates, media, tags, decks, review history and scheduling state. Due dates carry over. Exports .apkg for Anki 2.1 through 26.x and AnkiDroid.
  • FSRS-6Ported from fsrs-rs 6.6.2 and checked against its test vectors. Optimise fits the parameters to your reviews. SM-2 is a per-preset option.
  • Four platformsLinux, Windows, macOS and Android from one Rust engine. Light and dark themes; cards render Arabic, maths and code.
  • WorkloadCatch-up for backlogs, a daily time budget, and a 90-day forecast when you change new cards per day or desired retention.
  • StorageA SQLite file in the app-data directory, rotating automatic backups, an integrity check on open, and a full-backup zip of collection and media. No account.

First run

Import from Anki, Try a sample deck (30 cards with cloze, image, maths and Arabic) or Start empty. See Getting started.

Linux (AppImage)

curl -LO https://github.com/ZahakJ/loci-rs/releases/download/v0.2.1/Loci_0.2.1_amd64.AppImage && chmod +x Loci_0.2.1_amd64.AppImage && ./Loci_0.2.1_amd64.AppImage

.deb and .rpm are listed above.

Windows (PowerShell)

Invoke-WebRequest https://github.com/ZahakJ/loci-rs/releases/download/v0.2.1/Loci_0.2.1_x64_en-US.msi -OutFile Loci.msi; Start-Process .\Loci.msi

Or the -setup.exe installer.

macOS (Apple silicon)

curl -LO https://github.com/ZahakJ/loci-rs/releases/download/v0.2.1/Loci_0.2.1_aarch64.dmg && open Loci_0.2.1_aarch64.dmg

On Intel, replace aarch64 with x64. The build is not notarised: right-click Loci in Applications and choose Open (macOS 15+: System Settings, Privacy & Security, Open Anyway), or run xattr -cr /Applications/Loci.app.

Android (arm64)

curl -LO https://github.com/ZahakJ/loci-rs/releases/download/v0.2.1/loci-v0.2.1-android-arm64.apk && adb install loci-v0.2.1-android-arm64.apk

Or open the APK link on the phone. Android 7.0 (API 24) or newer; the universal APK covers every ABI.

From source

git clone https://github.com/ZahakJ/loci-rs && cd loci-rs/apps/loci && pnpm install && pnpm tauri build

Needs Rust, Node and pnpm; see Getting started.
