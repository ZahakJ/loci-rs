Your Anki years, scheduled by FSRS-6, in one app for desk and phone.

Loci imports your Anki collection with every review and due date intact, runs natively on Linux, Windows, macOS and Android, and keeps everything in one SQLite file on your own device.

The captures show the synthetic fixture collection (402 notes, 590 cards, three years of simulated history) rendered by the app's own interface against the Rust engine; no real deck was used.

Three screens

Study

Four buttons that never move

  • Again, Hard, Good and Easy sit in fixed positions, and each shows the interval it would give before you press it.
  • Keys 1–4 grade; space shows the answer, then means Good.
  • Press i on any card for Why this interval?: the chance you would recall it now, its stability, its difficulty and its last reviews.

Catch-up and workload

A backlog becomes a plan

  • Catch-up states the debt in minutes and offers four plans: spread it over several days, just today's share, lower retention for a week, or study everything. Each can be undone.
  • Each preset has a daily time budget in minutes instead of card caps.
  • Momentum, the days studied in the last 30, replaces streaks: a missed day is shown and nothing resets.

Browse and add

Anki's search, in a table that stays fast

  • The search box reads Anki's syntax: deck:, tag:, is:due, prop:r<0.8, rated:7, phrases, OR and parentheses.
  • Bulk actions on a selection: change deck, tags, suspend, flag, set due date, forget, find and replace. All undoable.
  • The Add sheet (a from anywhere) writes cloze notes and draws image occlusions in Anki's own format.

What it is

  • A real Anki replacementImports .apkg and .colpkg from every Anki version, legacy and current layouts, with notes, note types, templates, media, tags, decks, review history and scheduling state. A card due tomorrow in Anki is due tomorrow here. Exports back to an .apkg that Anki 2.1 through 26.x and AnkiDroid read.
  • FSRS-6 by defaultPorted from the reference implementation (fsrs-rs v6.6.2) and tested against its published vectors. Optimise, in each preset's settings, fits the parameters to your own reviews. Anki's SM-2 is one switch away.
  • One app on four platformsNative builds for Linux, Windows, macOS and Android from one Rust engine and one interface. Light and dark themes are each designed, not inverted, and cards render Arabic, mathematics and code well.
  • Humane about workloadA catch-up mode for backlogs, a daily time budget instead of card caps, a workload forecast before you change new cards per day or desired retention, and momentum instead of streaks.
  • Data you ownA real SQLite file in your app-data folder, rotating automatic backups, restore, an integrity check on open, and a full-backup zip of collection and media. No account, no server, nothing leaves the device.

The first screen

An empty collection opens on one screen with three choices: Import from Anki, Try a sample deck (thirty cards about memory itself, with cloze, image, maths and Arabic cards) and Start empty. No account, no tour. Getting started walks through each.

Linux (AppImage)

curl -LO https://github.com/ZahakJ/loci-rs/releases/download/v0.1.0/Loci_0.1.0_amd64.AppImage && chmod +x Loci_0.1.0_amd64.AppImage && ./Loci_0.1.0_amd64.AppImage

The .deb and .rpm packages are in the list above.

Windows (PowerShell)

Invoke-WebRequest https://github.com/ZahakJ/loci-rs/releases/download/v0.1.0/Loci_0.1.0_x64_en-US.msi -OutFile Loci.msi; Start-Process .\Loci.msi

Or run the -setup.exe installer instead.

macOS (Apple silicon)

curl -LO https://github.com/ZahakJ/loci-rs/releases/download/v0.1.0/Loci_0.1.0_aarch64.dmg && open Loci_0.1.0_aarch64.dmg

On Intel, replace aarch64 with x64. The macOS build is not notarised: after dragging Loci to Applications, run xattr -d com.apple.quarantine /Applications/Loci.app once, or right-click and choose Open.

Android (arm64)

curl -LO https://github.com/ZahakJ/loci-rs/releases/download/v0.1.0/loci-v0.1.0-android-arm64.apk && adb install loci-v0.1.0-android-arm64.apk

Or open the APK link on the phone and allow installs from your browser. Android 7.0 (API 24) or newer; the universal APK covers every ABI.

From source

git clone git@github.com:ZahakJ/loci-rs.git && cd loci-rs/apps/loci && pnpm install && pnpm tauri build

Needs the pinned Rust toolchain, Node and pnpm; see Getting started.
